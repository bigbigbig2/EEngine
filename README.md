# OEngine

OEngine 是面向桌面浏览器 WebGPU、中大型高几何密度场景的 GPU-first 渲染引擎核心，目标是极致 GPU 性能与现代 AAA 画质。

当前目标是极致性能、GPU-Driven、WebGPU Native、AAA Rendering 与可持续扩展，由[极致性能重建设计](./docs/next-design/eengine-extreme-performance-rebuild-2026-10.md)统一。目标采纳不表示实现或性能验收完成。

OEngine Examples

R0 Observability Smoke

真实初始化 WebGPU/OEngine，采集 GraphicsContext 更新的 CPU、submit、readback、upload 与 counter 证据。

R0 Frame Smoke

执行真实 Renderer 主帧，渲染固定 Box 场景并采集 CPU/GPU 分段结果。

R1 Compute HZB Validation

验证 rg16float storage、同纹理跨 mip dispatch、奇数尺寸数值与单 Compute Pass 上界。

R2-A Package Kernel

验证 SourceGeometry、deterministic package、异步 reopen 和损坏 payload 拒绝；不创建 GPU 资源。

R2-B-01 Meshlet Cooker

浏览器运行官方 meshoptimizer 1.0.0，验证三组 recipe、新 Meshlet sections、reopen 和 triangle coverage。

R2-B Complete Geometry Package

验证可绘制层次/error、BVH8、未压缩 streams/material、完整 validator、确定性和纯 package reopen。

R2-C GPU Residency

验证紧凑 Geometry/Cluster ABI、全 section residency、grow/abort/release，以及 GPU producer → drawIndirect Hardware consumer。

R2-D Packed Scene

验证 1k/10k/100k bulk、显式 transform/material patch、previous-from-current，以及 Instance + Geometry 的 GPU compact → Hardware indirect 闭环。

R3-B Hierarchical Work Generation

验证 R2 resident tables 上的 InstanceCull、Cluster Frustum/SSE、ping/pong indirect rounds、容量 fallback 与 GPU/CPU selected-set 对齐。

R4-A-02 Hardware Opaque Producer

Production RasterWork drawIndirect into VisibilityKey v1 and reverse-Z depth, with validation-only GPU readback.

R4-A-03 Alpha-Tested Visibility

GPU Material Visibility records, UV transform, alpha texture/cutoff, sidedness and explicit fallback validation.

R4-A-04 Hardware Debug Resolve

Production packed glTF VisibilityKey heatmap plus GPU fail-visible lookup diagnostics.

R4-A-05 Visibility Lifecycle

Capacity rejection, resize/cut/view history, in-flight replacement, feature-off and fresh-device rebuild.

R5 FX-01 Surface Debug + Background

2×3 Packed 材质板、Surface GPU 数值 readback、确定性背景与 debug feature-off graph 证据。

Benchmark A · Teapot 160k contract

冻结 three.js Compute Rasterizer 最低线的 Teapot/LOD/160k 输入；链接默认使用不可入 gate 的 smoke profile。

Benchmark B · Helmet PBR/IBL contract

冻结 Damaged Helmet、材质纹理、环境资产和 15,625 布局；当前缺项在页面中明确列为 unsupported。

Benchmark C · Engine generality contract

同一主管线上的多几何、多材质、alpha-tested、本地灯光和动态 transform 场景。

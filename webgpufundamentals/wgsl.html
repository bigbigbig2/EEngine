本 Shader 用到的 WGSL

  • const / let / var：编译期、运行期不可变、可变存储
  • vec2f / vec4f / mat2x2f / array：复合类型
  • @vertex / @fragment：三个独立入口点
  • @builtin / @location：Pipeline 阶段接口
  • for / switch / select：控制流与条件选择

严格类型

mode 是 u32，循环计数是 i32；混合运算前用 f32(i) 显式转换。

入口点

Pipeline Descriptor 通过 entryPoint 从同一 Module 选择实际执行的 Vertex/Fragment 函数。

阶段接口

@builtin(position) 承担固定语义；@location(0) 让 UV 从 Vertex 传入 Fragment。

资源可达性

Pattern 经函数访问 params，因此需要 BindGroup；Solid 不可达该变量，所以不需要绑定。

Matrix Stacks：把局部变换嵌套起来

矩阵栈不是 GPU 功能，而是 JavaScript 侧的一种层级建模工具。调用 save() 保存父矩阵，在副本上应用子节点局部变换，绘制后用 restore() 回到父坐标系。 文件柜展示可复用部件，递归树展示函数调用栈与矩阵栈如何一一对应。

1 · save() 保存当前父矩阵，并复制一份作为子节点工作矩阵
2 · Local Transform 在栈顶追加子节点的 Translate / Rotate / Scale
3 · drawObject() 计算 ViewProjection × Model，上传对象 Uniform 并 Draw
4 · restore() 丢弃子节点变换，恢复父坐标系，继续绘制兄弟节点

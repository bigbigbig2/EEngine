Storage Texture：让 Compute Shader 直接写像素

本例没有 Vertex Shader、Fragment Shader，也没有 Render Pass。 每个 Compute Shader invocation 负责一个像素，并通过 textureStore 直接写入 Canvas 的当前纹理。

传统绘制：顶点 → 光栅化 → Fragment Shader → 颜色附件
本章方式：Compute Shader → textureStore(pixel, color) → Storage Texture

Workgroup 是 8 × 8。每个 invocation 根据 global_invocation_id.xy 找到唯一像素，因此不会发生多个线程写同一像素的竞态。

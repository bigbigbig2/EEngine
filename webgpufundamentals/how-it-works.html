CPU 类比中的 Vertex 输出

正在执行 JavaScript Vertex Shader 类比……
Uniforms

scale、textureMix、bufferInfluence；一次 Draw 内各 Invocation 相同。

Attributes

position、color、uv；固定功能按 stride/offset 为每个顶点提取。

Raw Buffers

Storage Buffer offsets；Shader 用 vertex_index 自己计算索引访问。

Textures

2×2 RGBA Texture；Sampler 在相邻 Texel 之间执行线性过滤。

Inter-stage

Vertex 输出 color/uv；光栅器为每个片段插值后传给 Fragment。

Constants

WGSL 的 POSITION_Z 与 OUTPUT_ALPHA，在 Shader 编译时已确定。

GPUExternalTexture：直接采样视频帧

点击启动后，左侧 Canvas 2D 会持续绘制动画，再通过 captureStream() 送入隐藏的 Video。WebGPU 每帧调用 importExternalTexture，让 Shader 直接采样当前视频帧。

普通导入：Video → copyExternalImageToTexture → GPUTexture → textureSample
外部纹理：Video → importExternalTexture → GPUExternalTexture → textureSampleBaseClampToEdge

上图是 Canvas 2D 源；WebGPU 读取的实际对象是它生成的隐藏 HTMLVideoElement。

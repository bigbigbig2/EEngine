Vertex Buffer：交错属性与 Index Buffer

四个不同顶点组成一个矩形。每条顶点记录交错保存 position 和 color，六个索引决定两个三角形如何复用顶点。

WebGL：vertexAttribPointer + bindBuffer + drawElements
WebGPU：Pipeline buffers + setVertexBuffer + drawIndexed
每顶点步长
20 bytes
不同顶点
4
顶点数据
80 bytes
索引数据
12 bytes
索引访问
6
每条记录 20 字节
┌───────────────┬─────────────────────┐
│ position vec2 │ color vec3          │
│ offset 0      │ offset 8            │
│ 8 bytes       │ 12 bytes            │
└───────────────┴─────────────────────┘

indices:
0, 1, 2,  2, 1, 3

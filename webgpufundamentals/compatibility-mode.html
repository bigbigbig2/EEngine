Compatibility Mode：用受限路径覆盖更多 GPU

兼容性模式不是把 WebGL 包进 WebGPU，也不是遇到错误自动降级。应用主动请求一个限制更多的 Adapter，并让同一套 WebGPU 代码遵守这些限制，以便运行在只能映射到较旧图形能力的设备上。

请求关系

01 · Request 请求 Compatibility Adapter requestAdapter({ featureLevel: "compatibility" })
02 · Inspect 检查能否升级 Core adapter.features.has("core-features-and-limits")
03 · Device 本页故意保留 Compatibility 约束 adapter.requestDevice()

本示例遵守的关键约束

受限写法：Vertex Shader 随意读取 Storage Buffer

部分旧设备的 Vertex Stage 不支持 Storage Buffer，默认上限可能是 0。

本页写法：顶点位置和 UV 放进 Vertex Buffer

Vertex Fetch 是 WebGL 2 级设备普遍具备的路径，也符合 Core WebGPU。

受限写法：绑定时创建单层 2D 子视图

Compatibility Mode 不允许在 Texture Binding View 中随意切换维度或选择图层子集。

本页写法：创建时固定 2d-array，绑定完整视图

FPS 不是 GPU 时间

FPS 来自相邻两次 requestAnimationFrame 回调的间隔，还会受到刷新率、后台标签页和浏览器调度影响。

JS 时间不等 GPU 完成

performance.now() 包围的是更新数组、写 Buffer、编码和提交命令；queue.submit() 返回时 GPU 通常仍在工作。

GPU 时间也不是最终性能

Timestamp 适合在同一设备上调试和比较 Pass；跨 GPU 结果不可直接类比，最终仍需 FPS、吞吐量和真实场景测试。

Draw 参数也是 Shader 输入

左右两栏使用同一个 ShaderModule 和同一条 RenderPipeline，也没有 Buffer 或 BindGroup。 左侧用三次 Draw 的 firstInstance 分别传入 0、1、2；右侧用一次真正的实例化 Draw 自动生成相同的三个 instance_index。

左侧：draw(3, 1, 0, firstInstance) → instance_index = firstInstance
右侧：draw(3, 3, 0, 0) → instance_index = 0、1、2
3 次 Draw · firstInstance = 0 / 1 / 2 1 次 Draw · instanceCount = 3

本帧录制的 Draw

  • draw(3, 1, 0, 0)
  • draw(3, 1, 0, 1)
  • draw(3, 1, 0, 2)
  • draw(3, 3, 0, 0)

两种方式得到相同图案，但语义不同。左侧把 firstInstance 当成一个免费的逐 Draw 索引； 右侧才是一次 Draw 绘制三个实例。

本例为什么给 Texture Readback 分配 512 bytes

实际一行像素：3 pixels × 4 bytes = 12 bytes
copyTextureToBuffer 要求：bytesPerRow 是 256 的倍数

row 0：12 bytes 像素 + 244 bytes padding
row 1：12 bytes 像素 + 244 bytes padding
总计：256 × 2 = 512 bytes

单层 2D Copy 的最小覆盖范围其实是 256 + 12 = 268 bytes；
本例给最后一行也保留完整槽位，是为了让行布局更直观。

# 产品预期与分档

> 来源：docs/source/webgpu-browser-limits.md §9；docs/source/comparison-three-vs-shade.md 小场景 vs 大场景；设计 v2 适用场景

## 1. 网页预期

```txt
几秒可交互倾向
不默认可占满机器
切标签页不应当游戏最小化随便处理
关闭即结束
```

## 2. 分档是设计一部分（母本精神）

```txt
高端桌面：更完整 TAA/SSR/GI/纹理预算
普通笔记本：降 DPR、半分辨率 SSR、简化 GI
移动/集显：关重效果、简单阴影、低纹理预算
后台标签：停或极低负载
```

## 3. 与架构上限的关系

```txt
架构按 Shade 方向设计上限
默认配置按网页预期收敛
用户显式选择高质量档时再拉满
```

禁止：

```txt
只有实验室全特效一条叙事
用小场景证明「全面超越 three」
```

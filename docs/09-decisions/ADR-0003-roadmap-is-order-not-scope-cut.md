# ADR-0003 · 路线图是顺序，不是砍范围

- **状态：** Accepted  
- **日期：** 2026-07-17  
- **影响模块：** 07-roadmap、产品叙事  

## 背景

设计 v2 含 Phase 0–11 与 TAA/SSR/GI/VB 等。实施上必须分期。存在把「未做」说成「不做」的风险。

## 决策

```txt
1. Phase 只约束建设顺序与阶段完成意图
2. 不通过路线图删除工程等式中的 Layer 3 能力
3. 降级 = 默认关或平台关，须可再打开或 ADR 暂缓
4. 长期跳过某能力必须 ADR，并引用设计 v2 原文条款
```

## 后果

```txt
+ 可诚实分期
+ 保护母本目标身份
− 对外沟通需同时说「现在到哪」和「最终公式」
```

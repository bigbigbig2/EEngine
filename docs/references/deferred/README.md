# Deferred 研究

本目录保存仍有调查价值、但不属于 OEngine 当前桌面 WebGPU 中大型场景路线的资料，包括：

- 超大世界坐标和完整 World Partition；
- Nanite/virtual geometry streaming 和 3D Tiles；
- Virtual Shadow Map、Virtual Texture 全套系统；
- ReSTIR/Lumen-like GI、ray tracing/path tracing；
- terrain/foliage/hair、animation/ECS 和完整 Gameplay 生命周期；
- 云、海洋、大气等专用效果。

Deferred 文档不能直接新增当前 Roadmap 任务。提升为当前能力前必须更新 `DIRECTION/TARGETS`，必要时新增 ADR，并给出目标 workload 和性能假设。

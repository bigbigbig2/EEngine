Bootstrap Priority Ranking

idle
Loads the same GLB twice with an identical camera and identical budgets. Run A sets no source priority, so its bootstrap cut is the 24 largest primitives by coverage; run B promotes the second coverage tier (ranks 24..47), which the unprioritized cut cannot contain. Both cuts are 24 primitives and disjoint, so the two scenes must contain different instances. If the catalog-priority handshake is dropped, both runs select the same coverage-ranked cut and the case fails.

# U0 Reference Experiments

Isolated feasibility tools, not a new runtime or a production codec dependency.
These are historical reference experiments, not the selected production route.
The replacement authority is
`docs/next-execution/eengine-extreme-web-asset-compression-execution-2026-10.md`
section 10, which withdraws the old broad route-rejection conclusions without
rewriting the measurements. `results.json` is a finite measured snapshot, not a
status tracker or full-scene/performance qualification. Its copied baseRevision
contains a typo; the actual P commit is
`5f3f41533e25901cbbd1da9c3ae751c64bc0a9c9`. No tool writes production assets.

## Run Serially From Repository Root

```powershell
npm --prefix OEngine run build:test
node OEngine/tools/web-asset-u0/build.mjs all
node OEngine/tools/web-asset-u0/texture.mjs
node OEngine/tools/web-asset-u0/geometry.mjs
node tools/gpu-oracle.mjs web-asset-u0 --json > .local/web-asset-u0/browser-result.json
node OEngine/tools/web-asset-u0/report.mjs
```

Check every exit code; do not generate a new snapshot from a failed browser run.
Do not rebuild the native executable during encoding, or regenerate fixtures
during browser use. Every binary/fixture/probe hash is captured. Encoding cache
hits require matching executable, canonical bytes, dimensions, semantic, quality
and both generated output hashes. Decode/quality comparisons still run.

`build.mjs native`, `wasm`, and `geometry` are partial build conveniences;
`all` is the reproducible native + WASM sequence. Generated sources/binaries and
raw logs stay in `.local/web-asset-u0/`. The generator strips an initial upstream
BOM when prepending declarations, exports only BC7-required initialization, and
patches allocation-failure behavior plus the Zstd context host adapter. It does
not replace the upstream predictor, entropy, logical-block or BC7 pack kernels.

The fixed 16MiB modules, size/arena gates and retry checks are bounded feasibility
evidence, not a formal proof of memory safety or the final shared Worker protocol.
GPU readback and submissions here are oracle work only, never production policy.
